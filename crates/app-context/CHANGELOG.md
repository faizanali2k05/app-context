# Changelog

## 0.1.0 (2026-10-10)

- Immutable typed Context and explicit duplicate/missing errors.
- Arc and borrowed retrieval, immutable context clones, independent scoped overrides.
- Explicit FromContext trait and optional derive with nested/generic state support.
- Optional Axum and Actix extractors and Tonic request-extension interceptor.
- Tests, compiling examples, CI and retrieval/initialization benchmarks.
