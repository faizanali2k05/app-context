# Code of conduct

Treat contributors and users respectfully. Discuss technical disagreements using
concrete evidence. Insults, harassment, discrimination, threats and sharing private
information without permission are unacceptable in issues, reviews or project
communication. Maintainers may remove abusive content, restrict participation or
ban repeated/severe violations, applying these rules consistently and fairly.

Report concerns privately using the repository owner's published contact:
https://github.com/faizanali2k05. If a private contact is unavailable, request one
through a repository issue without including personal or sensitive incident details.
This is a project policy, not a claim of affiliation with an external organization.
